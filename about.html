このサイトについて｜TagTune

TagTune とは

TagTune（タグチューン）は、ボカロ・J-POP・アニソン・歌ってみたを、聴いた人がつけた「爽やか」「エモい」などの印象タグで探せる、個人運営の非営利の音楽サイトです。広告はなく、収益化もしていません。

曲の情報の出どころ

曲の一覧は、毎朝自動で次のサービスから集めています。曲名・再生数・サムネイルなどの情報は、それぞれのサービスのものです。

  • ニコニコ動画：ニコニコ動画 スナップショット検索API
  • YouTube：YouTube API サービス（YouTube Data API）

このサイトは YouTube API サービスを利用しています。このサイトを使うことで、YouTube 利用規約に同意したものとみなされます。YouTube（Google）での情報の扱いについては Google プライバシーポリシーをご覧ください。

YouTube から取得した情報は毎日取り直していて、30日より古い情報を使い続けることはありません。削除・非公開になった動画は、次の更新でサイトから外れます。

ページ内での再生

サムネイルの ▶ を押すと、YouTube またはニコニコ動画の公式の埋め込みプレイヤーで再生します。動画はそれぞれのサイトから直接再生されていて、このサイトが動画を保存したり、配信し直したりすることはありません。

投稿者が埋め込みを許可していない動画は ▶ を出さず、リンクで動画サイトを開くだけにしています。

プレイヤーを開いたときは、YouTube またはニコニコ動画のプレイヤーが読み込まれ、それぞれのサービスの規約・プライバシーポリシーに沿って Cookie などが使われることがあります。

プライバシーポリシー

集める情報

  • タグの投票：はじめてタグを投票したときに、自動で匿名ログインします。名前・メールアドレスなどは使いません。保存するのは「ランダムに作られた利用者ID」「どの曲に、どのタグを、いつ押したか」だけです。
  • サイトに公開するのは、曲ごと・タグごとの票の数だけです。誰がどのタグを押したかは公開しません。
  • 歌ってみたのリクエスト：曲ページから送られた「曲」と「動画のURL」と「送られた日時」だけを保存します。誰が送ったかは保存しません。確認できた動画は、その曲の歌ってみたとしてサイトに載せます。

ブラウザに保存する情報

  • 匿名ログインの状態と、自分が押したタグを、ブラウザの保存領域（localStorage）に保存します。ブラウザのサイトデータを消すと消えます。
  • アクセス解析や広告のための Cookie は使っていません。

使っている外部サービス

  • Supabase：タグの投票の保存と集計
  • GitHub Pages：サイトの公開（GitHub がアクセスの記録を取ることがあります）
  • Google Fonts・jsDelivr：文字のフォントと、投票に使うプログラムの読み込み
  • YouTube・ニコニコ動画：サムネイルの表示と、ページ内での再生

これらのサービスには、閲覧したときの IP アドレスなどが送られます。扱いはそれぞれのサービスのプライバシーポリシーに従います。

自分の投票を全部消す

このブラウザで押したタグの票を、データベースからまとめて削除します（元には戻せません）。1つずつ消すときは、曲のタグをもう一度押してください。

著作権について

楽曲・動画・サムネイルの著作権は、それぞれの作者・権利者にあります。このサイトは動画サイトへのリンクと、公式の埋め込みプレイヤーでの紹介だけを行っています。

お問い合わせ・掲載の取り下げ

「自分の動画を載せないでほしい」「作者名などがまちがっている」などは、下のページからお知らせください。確認して、取り下げや修正をします。
