# TagTune（タグチューン）

https://alka9029.github.io/vocalo-tagcho/

ボカロ・J-POP・アニソン・歌ってみたを、聴いた人がつけた印象タグで探せるサイト（制作中）。

## いまできること

毎朝6時15分（日本時間）に、新しく投稿された曲を自動で集めて `data/songs.json` に保存する。

- **ニコニコ動画**：スナップショット検索APIで、直近3日の「VOCALOID」タグと「歌ってみた」タグの動画を再生数の多い順に取得
- **ニコニコ動画（再生数の更新）**：直近6か月の人気曲を取り直して、すでにある曲の再生数を新しくする（1か月以内の曲は新しく追加もする）
- **YouTube 新着検索**：直近7日に投稿された音楽動画を、キーワード（MV、歌ってみた、主題歌など）ごとに再生数の多い順で取得（要APIキー）
- **YouTube 急上昇**：音楽カテゴリの急上昇（日本）（要APIキー）
- **YouTube 再生数の更新**：投稿から35日以内の曲の再生数を毎日取り直す（要APIキー）
- **YouTube 自動フォロー**：サイトに載った曲のうち1万回以上再生された曲を出したチャンネルを `data/channels.json` に自動で登録し、毎日その新着をチェック。音楽カテゴリの日本の曲だけを追加する（ボカロの本家＝作曲者のチャンネルと、それ以外のチャンネルが半分ずつになるように枠を分ける。ボカロPは再生数3,000回以上から登録。曲が載らないチャンネルは、ボカロPは365日・それ以外は120日で自動で外す。要APIキー）
- **YouTube チャンネル（手動）**：`config.json` の `youtube.channels` に登録したチャンネルの新着動画（RSS、APIキー不要）

YouTubeのAPIキーは、リポジトリの Settings →「Secrets and variables」→「Actions」に `YOUTUBE_API_KEY` という名前で保存する。1日の無料枠は10,000ユニットで、今の設定だと1日あたり約800ユニット使う（新着検索のキーワード1つにつき100）。

取得した動画は自動でこう分類される：

| 項目 | 判定のしかた |
| --- | --- |
| 本家／歌ってみた | タグやタイトルに「歌ってみた」「cover」などがあるか |
| ジャンル（ボカロ／J-POP） | タグ、歌声の名前、YouTubeチャンネルの設定 |
| 曲名・作者・歌声 | 「曲名 / 作者 feat. 歌声」のようなタイトルの書き方から |
| 原曲とのひもづけ | 歌ってみたの曲名と同じ曲名の本家を探す |

## タグ投票（Supabase）

聴いた人が押したタグは、無料のデータベース Supabase に保存して、みんなの票として集計する。

- データベースの作り方は `supabase/schema.sql`（Supabase の SQL Editor に貼って実行）
- 投票する人は、初めて投票したときに自動で匿名ログインする（名前やメールは不要）。同じブラウザなら次からも同じ人として扱う
- 自分の票しか追加・取り消しできないように、データベース側で制限している。集計は曲ごと・タグごとの票数だけを公開
- 接続先は `index.html` の `SUPABASE_URL` と `SUPABASE_KEY`（公開用の鍵なのでサイトに載せてよい。**service_role の鍵は絶対に入れない**）
- 接続先が空のときは、今まで通りブラウザにだけ保存する

## 設定の変え方（`config.json`）

- `niconico.queries` の `minViews`：これ以上の再生数の動画だけ集める
- `niconico.lookbackDays`：何日前までの投稿を見るか
- `youtube.channels`：追いかけたいチャンネルを追加する

```json
{ "name": "チャンネル名", "channelId": "UCxxxxxxxxxxxxxxxxxxxxxx", "genre": "J-POP" }
```

`genre` は `ボカロ` / `J-POP` / `歌ってみた` のどれか。チャンネルIDはチャンネルページの「概要」→「チャンネルを共有」→「チャンネルIDをコピー」で取れる。

## 判定がまちがっていたとき（`data/overrides.json`）

動画のIDごとに正しい値を書いておくと、次の取得のときに上書きされる。

```json
{
  "nico:sm12345678": { "kind": "歌ってみた", "of": "nico:sm00000001" },
  "yt:abcdEFGhijk": { "g": "J-POP", "p": "アーティスト名" }
}
```

## 手動で動かす

GitHubの「Actions」タブ →「曲データを自動取得」→「Run workflow」。

手元で試すときは（Node.js 22以上）：

```sh
node scripts/fetch.mjs                               # 本番の取得
node scripts/fetch.mjs --fixture test/fixture.json   # テスト用データで判定だけ確認
```

## 注意

- ニコニコのスナップショット検索APIは**営利目的での利用が禁止**されている。広告などで収益化する場合は利用規約を確認すること。
- ニコニコの検索結果には投稿者名が含まれないため、タイトルに作者名がない動画は作者が空になる。必要に応じて `overrides.json` で補う。
